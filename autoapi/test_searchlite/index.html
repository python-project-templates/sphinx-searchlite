API

Intro to the API.

Gadgets
-------

Things that frob\ *nicate*.

.. py:function:: legacy(x)
   :no-index:

   Kept for older callers.

.. py:function:: over(a)
                 over(a, b)

   Overloaded.

.. cpp:class:: template<typename T> ns::Thing

   A templated thing.

.. py:class:: Gadget

   A gadget that frobnicates.

   .. py:method:: spin(speed)

      Spins the gadget sprocket.

.. py:data:: TIMEOUT

   Seconds before the gadget gives up.

.. py:module:: north

.. py:class:: Client

   Northern client.

   .. py:method:: connect()

      Opens the northern connection.

.. py:module:: south

.. py:class:: Client

   Southern client.

   .. py:method:: connect()

      Opens the southern connection.

.. cpp:namespace:: tools

.. cpp:class:: Socket

   Network socket.

   .. cpp:function:: void open()

      Opens the socket.

.. c:struct:: Data

   C structure.

   .. c:member:: int count

      Counts the entries.
